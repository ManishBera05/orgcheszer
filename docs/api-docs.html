3. Matchmaking & Gameplay

Endpoints for generating pairings and submitting game results

Generate next round

Organizer triggers API to generate pairings. Organizer only.

Authorizations:
bearerAuth
path Parameters
tournamentId
required
string <uuid>

Responses

Generated server url

http://localhost:8080/api/tournaments/{tournamentId}/rounds/generate

Submit game result

Staff or Organizer submits a match result.

Authorizations:
bearerAuth
path Parameters
tournamentId
required
string <uuid>
gameId
required
string <uuid>
query Parameters
result
required
string
Enum: "PENDING" "WHITE_WINS" "BLACK_WINS" "DRAW" "BYE"

Responses

Generated server url

http://localhost:8080/api/tournaments/{tournamentId}/games/{gameId}/result

2. Tournament Management

Endpoints for creating, viewing, and managing tournaments

Get specific tournament

Public endpoint to view tournament details.

path Parameters
tournamentId
required
string <uuid>

Responses

Generated server url

http://localhost:8080/api/tournaments/{tournamentId}

Update tournament details

Only the specific Organizer of this tournament can update it.

Authorizations:
bearerAuth
path Parameters
tournamentId
required
string <uuid>
Request Body schema: application/json
required
tournamentName
string

Official name of the event

startDateTime
string <date-time>

Date and time the first round begins

numberOfRounds
integer <int32>

Total number of rounds to be played

maxParticipants
integer <int32>

Maximum player capacity

entryFee
integer <int32>

Entry fee

description
string

Information about the tournament

location
string

Physical address or online link

timeControl
string

Standard chess time control format

format
string

Format of the tournament. Currently supports SWISS or ROUND_ROBIN

Responses

Generated server url

http://localhost:8080/api/tournaments/{tournamentId}

Request samples

  • Payload
Content type
application/json
{
  • "tournamentName": "Winter Grandmaster Open",
  • "startDateTime": "2030-01-01T10:00:00",
  • "numberOfRounds": 9,
  • "maxParticipants": 100,
  • "entryFee": 2500,
  • "description": "Unrated Swiss tournament with exciting prizes.",
  • "location": "Oslo Chess Club",
  • "timeControl": "90+30",
  • "format": "SWISS"
}

1. Authentication

Endpoints for User Registration and Login

Register a new user

Creates a new user account. No token required.

Request Body schema: application/json
required
firstName
string

Player's first name

lastName
string

Player's last name

email
string

Valid email address for login

password
string

Strong password

mobileNo
string

Contact number

dob
string <date>

Date of Birth

fideId
string

Official FIDE ID (Optional)

Responses

Generated server url

http://localhost:8080/api/auth/register

Request samples

  • Payload
Content type
application/json
{
  • "firstName": "Magnus",
  • "lastName": "Carlsen",
  • "email": "magnus@example.com",
  • "password": "SecurePass123!",
  • "mobileNo": "123456789",
  • "dob": "2000-01-01",
  • "fideId": "1503014"
}
